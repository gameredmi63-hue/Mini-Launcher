# Mini Launcher (Niagara-style)

Minimal Kotlin launcher: big clock, left-aligned app list, A–Z side bar with wave effect,
spring press animations, edge fading, scale-up launch. No third-party UI libs.

## Build the APK
**GitHub Actions (no PC needed):** push this folder to a new GitHub repo ->
Actions -> "Build APK" -> download the `MiniLauncher-apk` artifact.

**Android Studio:** File -> Open this folder -> Build -> Build APK(s).
Output: app/build/outputs/apk/debug/app-debug.apk

## Set as home app
Install the APK, press Home, choose "Mini Launcher" -> Always.
(Or Settings -> Apps -> Default apps -> Home app.)
